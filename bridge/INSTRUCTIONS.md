# INSTRUCTIONS — 指示を書き込む場所

このファイルは「チャット側の Claude（脳）」が指示を書き込む場所。
Mac 側の worker が未処理の指示を上から順に実行する。

## 書き方のルール（チャット側 Claude 向け）

- 新しい指示は、このファイルの一番下に追記する（上は消さない）。
- 1 つの指示は `## 指示 <ID>` の見出しから始める。ID は `年-月-日-連番`（例 `2026-09-24-001`）。
- 各項目は必ず書く：日時 / 状態 / 対象 / 内容。
- 状態は次の 4 つだけ：
  - `未処理` … まだ実行されていない（チャット側はこれで書く）
  - `実行中` … worker が今やっている（worker が書き換える）
  - `完了` … 終わった（worker が書き換える）
  - `要承認` … 危険なので人の許可待ち（worker が書き換える。削除・本番公開・課金・認証など）
- `状態` の行は worker が自動で書き換える。チャット側は最初の `未処理` だけ書けば OK。

## ひな形（このまま下にコピーして使う）

```
## 指示 YYYY-MM-DD-NNN
- 日時: YYYY-MM-DD HH:MM
- 状態: 未処理
- 対象: company-os
- 内容: （ここに指示を 1 つだけ、具体的に書く）
```
